## 3. How to Switch Between Local Adapter and Live OpenAI / Anthropic

To run the identical evaluation pipeline against a live LLM (e.g. OpenAI GPT-4o or Anthropic Claude 3.5 Sonnet):

1. **Register Provider with Type `OPENAI` or `ANTHROPIC`:**
   ```json
   POST /api/v1/providers
   {
     "name": "Production OpenAI",
     "provider_type": "OPENAI",
     "credentials": {"api_key": "sk-proj-..."}
   }
   ```
2. **Register Model Target:**
   ```json
   POST /api/v1/models
   {
     "name": "GPT-4o Production",
     "model_identifier": "gpt-4o",
     "provider_id": "<openai_provider_id>"
   }
   ```
3. **Trigger Evaluation:**
   - The backend `ModelGateway` automatically instantiates `OpenAIProviderAdapter` and performs live HTTPS completions to `https://api.openai.com/v1/chat/completions`.
   - The evaluators, metric aggregators, release decision rules, and audit log operate identically regardless of whether `LOCAL`, `OPENAI`, or `ANTHROPIC` is chosen.
