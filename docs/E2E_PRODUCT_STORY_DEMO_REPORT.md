## 1. What AIREX Actually Does & Business Value

### The Core Problem AIREX Solves
Deploying Generative AI applications to production carries substantial operational and brand risks:
1. **Hallucinations & Incorrect Answers:** AI providing factually inaccurate policy or billing details.
2. **Unsafe & Sensitive Data Exposure:** Leaking customer PII or responding to adversarial prompt injections.
3. **Unpredictable Latency & High Costs:** Latency spikes exceeding SLA limits and excessive token consumption.
4. **Broken Agent Tool-Calling:** Autonomous agents calling tools with invalid JSON schemas or falling into recursive loops.
5. **Silent Model Regressions:** Upgrading a base model or prompt template causing regressions on edge cases.

### How AIREX Solves It
AIREX provides a **systematic pre-release quality gate and continuous observability platform**:
* **Inputs Provided by User:** Benchmark test datasets (CSV/JSONL customer scenarios), evaluation rubrics (deterministic regex/bounds + LLM judge criteria), and model endpoint configurations.
* **Processing Performed by AIREX:** Model Gateway executes test matrices with bounded concurrency, runs multi-dimensional evaluation pipelines, compares candidate vs baseline regressions, and evaluates agent tool-calling trajectories.
* **Output Generated by AIREX:** Quantitative reliability scorecards (accuracy %, p50/p95/p99 latency, token costs, failure clustering) and an **automated Go/No-Go Release Decision** (`PASS`, `WARNING`, `BLOCKED`) backed by tamper-evident audit evidence.

## 2. Where AI Is Genuinely Used vs Rule-Based Algorithms

| Capability | AI Model Used? | Technology / Engine | Purpose | Output |
| :--- | :---: | :--- | :--- | :--- |
| **Model Ingestion & Gateway** | No | SQLAlchemy + Fernet Encryption | Encrypts API keys at rest; rate-limits requests | Masked provider catalog |
| **Dataset Ingestion** | No | Pydantic Schema Validator | Validates test variables & ground truth | Versioned test suite snapshot |
| **Model Response Generation** | **YES** | Local Gateway / OpenAI / Anthropic | Executes test prompts against model endpoints | AI text response + token stats |
| **Rule-Based Evaluators** | No | Python Regex, JSONSchema, Math | Checks string exactness, bounds, JSON syntax | Binary Pass/Fail + score |
| **LLM-as-a-Judge Evaluator** | **YES** | Judge Model (e.g. GPT-4o / Claude) | Grades nuanced tone, safety, groundedness | Score $[0, 1]$ + explanation |
| **Statistical Aggregation** | No | Math Quantiles / NumPy | Calculates p50, p95, p99 latency & cost | Executive summary metrics |
| **A/B Experiment Engine** | **YES** | Model Gateway Matrix | Evaluates Baseline vs Candidate variants | Regression delta metrics |
| **Agent Trajectory Testing** | **YES** | Deterministic Tool Agent / Gateway | Traces multi-step tool calls & detects loops | Agent Readiness Score $[0, 100]$ |
| **Go/No-Go Release Decision** | No | Deterministic Policy Engine | Evaluates aggregated evidence against SLA rules | Pass / Warning / Block verdict |
| **Live Observability** | No | OpenTelemetry-compatible Ingestion | Ingests spans and redacts customer PII | Real-time trace waterfall |
| **Compliance & Audit Center** | No | Cryptographic Audit Repository | Immutably records releases & legal holds | Tamper-evident evidence bundle |

## 4. Complete 10-Scene Story Flow

1. **Scene 1 — Executive Reliability Command Center:**  
   Overview of platform health, active subsystem indicators, and fleet status.
2. **Scene 2 — Project Workspace & Model Isolation:**  
   Creation of isolated workspace `Customer Support AI — v2.4 Release Gate`.
3. **Scene 3 — Model Catalog & Secure Gateway:**  
   Model configuration with encrypted credentials and connection testing.
4. **Scene 4 — Customer Support Benchmark Datasets:**  
   Management of versioned test cases covering refund policies, order lookups, and safety prompts.
5. **Scene 5 — Multi-Criteria Reliability Rubrics:**  
   Combination of deterministic formatting rules and LLM-as-a-judge safety criteria.
6. **Scene 6 — Live Evaluation Execution & Score Breakdown:**  
   Real-time execution displaying accuracy, p95 latency percentiles, and cost estimates.
7. **Scene 7 — Model Version A/B Regression Comparison:**  
   Side-by-side performance comparison of Candidate vs. Baseline models.
8. **Scene 8 — Autonomous Agent Tool-Calling & Loop Safety:**  
   Multi-step agent trajectory inspection and loop trap detection.
9. **Scene 9 — Go/No-Go Release Decision Policy Gate:**  
   Automated release policy gate checking SLA thresholds to prevent unsafe deployments.
10. **Scene 10 — Observability & Governance:**  
    Live waterfall traces with automated customer PII redaction and immutable compliance audit log.
